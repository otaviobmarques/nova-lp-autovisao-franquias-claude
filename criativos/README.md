# Criativos das campanhas de captação de franqueados

Peças geradas no padrão do Design System Auto Visão v1.1. Esta pasta existe para hospedar os arquivos
com link público (a Meta e o Google exigem uma URL para importar a mídia). **Não precisa ir para o site.**

| Arquivo | Uso |
|---|---|
| `num-*` | Prospecção: números da rede (+240 lojas, +18 estados, +80 mil laudos/mês) |
| `dono-*` | Prospecção: "Não precisa ser mecânico" (foto do franqueado) |
| `matriz-*` | Prospecção: 12 áreas de suporte da matriz |
| `mercado-*` | Prospecção: 15,8 mi de usados negociados em 2024 (Fenabrave) |
| `servicos-*` | Prospecção: 11 serviços |
| `video-numeros-*` | Prospecção: vídeo de 12 s com os números da rede |
| `rgrand-*` | Remarketing de venda: grandeza da rede (+240 lojas) |
| `rknow-*` | Remarketing de venda: know-how (+15 anos, +80 mil laudos/mês) |
| `restr-*` | Remarketing de venda: estrutura (12 áreas da matriz) |
| `rdec-*` | Remarketing de venda: decisão (consultar a cidade) |
| `dep1-*`, `dep2-*` | Remarketing: depoimentos de franqueados + números |
| `google-*` | Google Ads: imagens sem texto sobreposto (1,91:1 e 1:1) |

Formatos: `-1x1` = 1080×1080 (feed), `-9x16` = 1080×1920 (Stories/Reels, com zona segura).

## v2 (`v2/`): um "DNA" do Design System por peça

| Arquivo | Linguagem (DS p.3 e p.23) | Mensagem |
|---|---|---|
| `v2-abertura-*` | Abertura: foto ampla + faixa vermelha | Seu próximo negócio pode ser Auto Visão |
| `v2-institucional-*` | Institucional: fundo branco, título em duas cores | +240 lojas. A próxima pode ser a sua |
| `v2-tecnologia-*` | Tecnologia: fundo escuro, carro em destaque | Vistoria 360° · 11 serviços |
| `v2-comparativo-*` | Comparativo dividido | Abrir sozinho × abrir Auto Visão |
| `v2-laudo-*` | Prova: o laudo como produto | +80 mil laudos por mês, mesmo padrão |
| `v2-depoimento-*` | Prova social em vermelho | "Uma das melhores decisões que já tomei" |
