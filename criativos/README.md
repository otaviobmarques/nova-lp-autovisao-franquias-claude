# Criativos das campanhas de captação de franqueados

Peças geradas no padrão do Design System Auto Visão v1.1. Esta pasta existe para hospedar os arquivos
com link público (a Meta e o Google exigem uma URL para importar a mídia). **Não precisa ir para o site.**

| Arquivo | Uso |
|---|---|
| `num-*` | Prospecção: números da rede (+240 lojas, +18 estados, +80 mil laudos/mês) |
| `dono-*` | Prospecção: "Não precisa ser mecânico" (foto do franqueado) |
| `matriz-*` | Prospecção: 12 áreas de suporte da matriz |
| `mercado-*` | Prospecção: 15,8 mi de usados negociados em 2024 (Fenabrave) |
| `servicos-*` | Prospecção: 11 serviços |
| `video-numeros-*` | Prospecção: vídeo de 12 s com os números da rede |
| `dep1-*`, `dep2-*` | Remarketing: depoimentos de franqueados + números |
| `google-*` | Google Ads: imagens sem texto sobreposto (1,91:1 e 1:1) |

Formatos: `-1x1` = 1080×1080 (feed), `-9x16` = 1080×1920 (Stories/Reels, com zona segura).
